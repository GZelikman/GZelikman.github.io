This project is a web application with a backend written in Python using FastAPI and a frontend written in Javascript.
This Application is meant to be for a bar, where you can order drinks on the "Market". The Prices of the drinks will change based on demand and a little randomness. The Idea for this project is inspired by Barcelona’s “Dow Jones Bar”, so I wanted to recreate it. The picture below shows the final product the customer would see on the order Tablet (The Tablet is needed, as it displays the current prices and allows for easy ordering).

If one presses on Item on the Market, an ordering Pop-up will appear. In this Pop-up the user can track past prices and place their order. In the Ordering process the user can select the quantity and confirm their order.

To be able to show the current prices, as well as the past prices, the backend keeps track of all price changes and user orders in a Json File. The Graph seen in the picture above, is created by plotting the data in the backend and sending it via a base64 encoded png.

After currently 50 ordered Drinks a marketcrash will appear for 2 mins, this marketcrash will cause all the prices to change to the minimum price, this is meant for extra fun, as well, to not inflate the prices after to many Orders

After the costumer experience, the bartender experience should also be taken into account. This includes giving a tablet a tablenumber, see orders, create the bill, add or delete drinks and statistics. currently the admin can only asign tablenumbers and see the orders, but in the future I want to add the rest of the functionality.

Before opening the index.html file, where the costumers can see current prices and Order Drinks, the bartender needs to input the table number, as seen in the picture above.
